# Facebook Clone (Primitive)

A full-stack social media web application clone. This project features a decoupled architecture with a dedicated RESTful API backend and a dynamic, component-based frontend.

## 🛠️ Implementation Details & Tech Stack

This project is built using the **MERN** stack (MongoDB, Express, React, Node.js) and is structured as a monorepo containing both the client and server code.

### Frontend
* **Framework:** React.js
* **Build Tool:** Vite (for fast, optimized development and bundling)
* **Routing:** React Router DOM (v6) for client-side navigation (e.g., Feed, Create Post)

### Backend
* **Runtime:** Node.js
* **Framework:** Express.js (for handling API requests and routing)
* **Database:** MongoDB (connected via standard URI strings)
* **Environment Management:** `dotenv` for securing sensitive credentials
